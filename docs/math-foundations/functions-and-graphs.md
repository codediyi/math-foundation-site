# 函数、图像与变化率

> 微积分前先理解函数。函数不是公式列表，而是“输入如何变成输出”的规则；导数是输出对输入变化的敏感度。

## 学习目标

- 理解函数、图像、单调性、斜率和局部变化率。
- 掌握线性函数、二次函数、指数、对数、sigmoid、softmax 的基础直觉。
- 能解释导数、偏导和链式法则为什么是反向传播的核心。
- 能用代码画出函数并观察梯度变化。

## 为什么要学

深度学习模型本质上是一个大函数：

\[
\hat{y}=f_\theta(x)
\]

训练就是调参数 \(\theta\)，让损失函数 \(L(\theta)\) 变小。如果函数、斜率、导数没有理解清楚，后面学优化、矩阵微分、反向传播会很吃力。

## 函数是什么

函数是一条规则：给定输入，产生输出。

| 函数 | 公式 | 普通语言 |
|---|---|---|
| 线性函数 | \(f(x)=ax+b\) | 输入变大，输出按固定速度变化 |
| 二次函数 | \(f(x)=x^2\) | 离 0 越远增长越快 |
| 指数函数 | \(f(x)=e^x\) | 增长速度随自身变大 |
| 对数函数 | \(f(x)=\log x\) | 大数压缩，小数区分更明显 |
| sigmoid | \(f(x)=1/(1+e^{-x})\) | 把实数压到 0 到 1 |

## 图像怎么读

读函数图像时看四件事：

1. 输入范围是什么。
2. 输出范围是什么。
3. 函数是上升、下降还是先降后升。
4. 哪些位置变化快，哪些位置变化慢。

例如 sigmoid 在中间变化快，两端变化慢。这意味着输入很大或很小时，梯度接近 0，容易出现饱和。

## 斜率和导数

直线的斜率：

\[
k=\frac{\Delta y}{\Delta x}
\]

导数是“非常小范围内的斜率”：

\[
f'(x)=\lim_{h\to 0}\frac{f(x+h)-f(x)}{h}
\]

直觉：导数告诉你，如果输入 \(x\) 增加一点点，输出 \(f(x)\) 会增加还是减少，变化快还是慢。

## 常见导数

| 函数 | 导数 | 直觉 |
|---|---|---|
| \(x^2\) | \(2x\) | 离 0 越远变化越快 |
| \(e^x\) | \(e^x\) | 指数的变化率等于自身 |
| \(\log x\) | \(1/x\) | 小数附近变化大，大数附近变化小 |
| \(ax+b\) | \(a\) | 线性函数变化率固定 |

## 链式法则

如果：

\[
y=f(g(x))
\]

那么：

\[
\frac{dy}{dx}=\frac{dy}{dg}\frac{dg}{dx}
\]

普通语言：最终输出对输入的影响，等于每一层局部影响连乘。反向传播就是在大型计算图上反复使用链式法则。

## 多变量函数和偏导

模型损失通常依赖很多参数：

\[
L=L(w_1,w_2,\ldots,w_n)
\]

偏导 \(\frac{\partial L}{\partial w_i}\) 表示只改变 \(w_i\)，其它参数暂时固定时，损失如何变化。

梯度把所有偏导收集成一个向量：

\[
\nabla L=\left[\frac{\partial L}{\partial w_1},\ldots,\frac{\partial L}{\partial w_n}\right]
\]

梯度下降用负梯度方向更新参数：

\[
w \leftarrow w-\eta\nabla L
\]

## 指数、对数和 softmax

softmax 用指数把分数变成正数：

\[
p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
\]

如果某个 \(z_i\) 比其它值大很多，\(e^{z_i}\) 会占据绝大多数比例，softmax 接近 one-hot。这就是 logits 过大导致饱和的原因。

稳定实现通常先减最大值：

```python
import torch

z = torch.tensor([1000.0, 1001.0, 1002.0])
p = torch.softmax(z - z.max(), dim=0)
print(p)
```

## 画函数观察直觉

```python
import torch

x = torch.linspace(-5, 5, 11)
sigmoid = 1 / (1 + torch.exp(-x))
print(torch.stack([x, sigmoid], dim=1))
```

如果环境支持画图，可以把 `x` 和 `sigmoid` 画出来。重点不是图好看，而是观察：两端输出接近 0 或 1，中间变化最快。

## 与 Transformer 的关系

| 函数概念 | Transformer 中的位置 |
|---|---|
| 线性函数 | embedding 投影、Q/K/V/O、FFN |
| 指数函数 | softmax attention 权重 |
| 对数函数 | cross entropy、log likelihood |
| 导数 | 反向传播和优化 |
| 链式法则 | 多层网络梯度传播 |
| 饱和 | softmax 过尖、梯度变小 |

## 常见误区

- 把导数只当成公式表，不理解变化率。
- 忽略函数输入输出范围。
- 认为梯度大一定好；梯度过大可能导致数值不稳定。
- 认为 softmax 输出都是可信概率；它只是归一化权重，未必校准。
- 忘记链式法则中每一层都会影响最终梯度。
