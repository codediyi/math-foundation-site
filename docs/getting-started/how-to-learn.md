# 如何学习这套数学基础

## 学习目标

学完本页后，你应该能建立一套稳定的学习循环：先理解对象，再手推公式，再写最小代码，最后用实验验证直觉。数学学习的目标不是记住更多符号，而是让每个符号都能落到 Transformer 的张量、梯度、损失或实验现象上。

## 为什么要学

Transformer 论文里的公式通常不难，难的是判断公式在结构和训练中承担什么作用。例如 \(QK^\top\) 是矩阵乘法，也是相似度计算、信息路由、显存瓶颈和梯度传播通道。只会套公式会导致读论文时“看懂每一行但不知道它为什么有效”。

## 核心方法

| 维度 | 最低要求 | 产出 |
|---|---|---|
| 概念 | 能说清对象、形状、输入输出 | 概念卡片 |
| 推导 | 能手推关键等式和梯度 | 一页推导 |
| 实现 | 能写 NumPy/PyTorch 最小版本 | 可运行代码块 |
| 实验 | 能改变一个变量并观察结果 | 小图表或表格 |

## 最小练习

选择一个概念，例如 softmax。写出：

1. 定义：输入、输出、维度。
2. 直觉：为什么输出像概率分布。
3. 公式：平移不变性和温度缩放。
4. 代码：稳定 softmax。
5. 实验：改变温度，观察熵的变化。

## 阶段产出

每周至少沉淀三样东西：一页概念笔记、一页推导笔记、一段可运行代码。不要等“学完整章”再总结，数学能力来自小闭环的重复。
