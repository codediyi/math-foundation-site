# 实验日志与复盘

## 学习目标

学会把数学直觉转成可复现实验。实验日志不只是记录结果，更要记录假设、控制变量、失败原因和下一步修改。

## 实验日志结构

| 区块 | 内容 |
|---|---|
| 问题 | 本次实验验证什么数学或结构假设 |
| 设置 | 数据、模型、超参、随机种子、硬件 |
| 控制变量 | 哪些变量固定，哪些变量改变 |
| 指标 | loss、梯度范数、注意力熵、长度外推、延迟等 |
| 结果 | 表格、图、异常现象 |
| 结论 | 支持了什么，否定了什么 |
| 下一步 | 改哪一个变量，为什么 |

## Transformer 场景示例

假设问题是“Pre-LN 是否比 Post-LN 更稳定”。不要只跑一次 loss，而要记录：

- 相同模型深度、宽度、数据和优化器。
- 不同归一化位置。
- loss 曲线、梯度范数、激活范数。
- 是否出现 warmup 依赖、梯度爆炸或训练早期震荡。

## 最小练习

做一个二次函数优化实验：

1. 固定函数 \(f(x)=x^\top A x\)。
2. 改变 \(A\) 的条件数。
3. 比较不同学习率下 GD 是否发散。
4. 用结果解释“条件数影响优化稳定性”。

## 阶段产出

每个实验至少产出一张表和一句结论。结论必须能被指标支持，不能写成“感觉更稳定”。
