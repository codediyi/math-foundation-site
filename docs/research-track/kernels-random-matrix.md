# 核方法与随机矩阵

## 学习目标

理解核方法、随机特征、随机矩阵谱分布和初始化尺度。目标是读懂 Performer、无限宽极限、参数化尺度和训练动力学相关论文。

## 为什么要学

很多高效 attention 方法本质上是在近似 softmax kernel；很多训练稳定性问题与随机初始化下的谱和方差传播有关。

## 核心概念

- kernel trick 和 RKHS 直觉。
- 随机特征近似。
- 随机矩阵奇异值分布。
- 谱范数、Frobenius 范数、条件数。
- 宽度极限与参数化尺度。

## Transformer 对应关系

| 概念 | 对应问题 |
|---|---|
| kernel | softmax attention 的相似度函数 |
| 随机特征 | Performer/FAVOR+ |
| 谱分布 | 初始化和 logits 尺度 |
| 参数化尺度 | \(\mu P\)、unit scaling |

## 最小练习

随机生成不同宽度的权重矩阵，画奇异值分布，观察宽度变化如何影响谱尺度。

## 阶段产出

写一页笔记：核近似为什么可能把 \(O(N^2)\) attention 转成 \(O(N)\)，以及这种转换牺牲了什么。
