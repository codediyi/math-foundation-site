# 分析与泛函入口

## 学习目标

建立严格分析和泛函分析的最低入口：极限、连续、一致连续、完备性、Hilbert 空间、线性算子和谱。目标是服务理论论文阅读，而不是系统学习完整数学专业课程。

## 为什么要学

当论文讨论无限宽、无限深、核极限、算子谱或收敛性时，只会有限维矩阵直觉不够。泛函分析提供了把向量、函数、核和算子统一起来的语言。

## 核心概念

- 度量空间和完备性。
- Banach/Hilbert 空间。
- 连续线性算子。
- 对偶空间和内积表示。
- 谱和算子范数。

## Transformer 对应关系

| 分析概念 | 对应研究问题 |
|---|---|
| 交换极限和期望 | 无限宽/深极限 |
| Hilbert 空间 | kernel 和 attention 相似度 |
| 线性算子 | 层变换、状态更新 |
| 谱 | 稳定性和传播尺度 |

## 最小练习

找一个训练稳定性论文中的 smoothness 或 Lipschitz 假设，写出它在有限维矩阵中的含义。
