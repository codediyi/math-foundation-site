# 结构改进实验

## 学习目标

学会把一个结构想法转成 controlled ablation。目标不是提出“看起来更复杂”的模块，而是明确假设、固定变量、选择 baseline，并用证据判断改动是否有效。

## 为什么要学

结构改进最常见的问题是变量混杂：改了模型、参数量、训练步数、数据、学习率和实现细节，最后不知道性能变化来自哪里。controlled ablation 是把想法变成研究结论的最低门槛。

## 核心概念

- 研究假设。
- baseline 和 oracle。
- 参数量/计算量对齐。
- 随机种子和重复实验。
- 指标、显著性和失败分析。

## 实验模板

| 区块 | 内容 |
|---|---|
| 假设 | 例如自适应 temperature 能稳定 logits |
| 改动 | 只改变 temperature 计算方式 |
| 固定 | 数据、模型宽度、训练步数、优化器 |
| 指标 | loss、grad norm、attention entropy、latency |
| 结论 | 哪些指标支持或反驳假设 |

## 最小练习

选择 RoPE vs ALiBi 做一个 toy 对比实验。固定模型和训练设置，只改变位置机制，比较长度外推结果。

## 阶段产出

写一份 2 页实验计划，包含问题、方法、baseline、指标、预期风险和失败后的排查顺序。
