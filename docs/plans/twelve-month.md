# 十二个月路线

## 总目标

在六个月基础上继续推进到“能读理论论文、能做结构改进、能写完整研究报告”。第 27-52 周是研究强化段。

## 强化阶段

| 周数 | 主题 | 重点问题 | 阶段产出 |
|---|---|---|---|
| 第 27-34 周 | 严格分析与尺度理论 | 极限、Hilbert 空间、随机矩阵、\(\mu P\) | 稳定性与尺度笔记 |
| 第 35-38 周 | 机制解释 | induction heads、retrieval heads、head ablation | 机制解释复现实验 |
| 第 39-42 周 | 长上下文 | 位置外推、高效 attention、cache 和记忆 | 长上下文方法地图 |
| 第 43-46 周 | 选题与实验设计 | 假设、baseline、benchmark、指标 | controlled ablation 方案 |
| 第 47-52 周 | 实验与报告 | 训练、分析失败、二轮修正、写作 | 可投稿风格报告或高质量复现报告 |

## 五个项目里程碑

1. 手写单头与多头 attention，并验证反向传播。
2. 比较 sinusoidal、RoPE、ALiBi 的位置机制。
3. 比较 Post-LN、Pre-LN、NormFormer/DeepNorm 的训练曲线。
4. 复现一个高效 attention 变体的简化版。
5. 做一个结构改进实验，例如 retrieval-head aware KV 压缩或自适应 temperature。

## 研究报告结构

| 部分 | 内容 |
|---|---|
| 问题 | 研究问题和为什么重要 |
| 数学动机 | 用公式说明改动来自哪里 |
| 方法 | 结构、复杂度、实现细节 |
| 实验 | baseline、数据、指标、控制变量 |
| 结果 | 表格、图、失败案例 |
| 局限 | 不成立的场景和后续工作 |

## 验收标准

一年结束时，应能把失败实验拆成数学假设、实现问题、数据问题或评估问题，而不是只说“效果不好”。
