# 数学基础到 Transformer 研究

这是一个 MkDocs Material 文档站，面向“从数学基础进入 Transformer 理解与结构改进”的学习路线。

## 本地开发

```bash
python3 -m pip install -r requirements.txt
mkdocs serve
```

## 构建

```bash
mkdocs build --strict
```

## 部署

目标仓库：

```text
https://github.com/codediyi/math-foundation-site
```

部署到 GitHub Pages：

```bash
mkdocs gh-deploy
```

站点地址：

```text
https://codediyi.github.io/math-foundation-site/
```
